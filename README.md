# Портфолио Семёна Ефанова

Статический сайт для GitHub Pages. Откройте `index.html` в браузере: установка и сборка не нужны. Все пути относительные, сайт работает и в подпапке репозитория.

## Содержание

- `index.html` — тексты и разделы.
- `style.css` — оформление и адаптация для телефона.
- `script.js` — просмотр изображений; Escape закрывает просмотр.
- `images/` — оригинальные утверждённые изображения без изменений.
- `documents/` — место для будущих PDF.

## Что нужно дополнить

1. Репозиторий: https://github.com/nepoveslo/nepoveslo.github.io. Профиль: https://github.com/nepoveslo.
2. Сертификат VK добавлен. Получить PDF резюме и добавить ссылку для скачивания.
3. Получить почту или Telegram для контактов.
4. Проверить актуальный код Weather App перед добавлением ссылки: сверить функции и отсутствие опубликованных ключей. Описание сейчас основано на ТЗ. Кэширование, debounce и автодополнение не заявлены.
5. При необходимости обновить курс обучения. В ТЗ указан второй курс.

Тестовое ЦФТ исключено по пожеланию владельца. Дополнительные сертификаты можно добавить после получения файлов.
