# Портфолио Семёна Ефанова

Статический сайт для GitHub Pages: https://nepoveslo.github.io/.
Откройте `index.html` в браузере. Установка и сборка не нужны.

## Структура

- `index.html` — первая карточка, образование, навыки, материалы и контакты.
- `style.css` и `desk.css` — оформление, фон и адаптация для телефона.
- `script.js` — увеличение изображения карточки; Escape закрывает просмотр.
- `documents/TestApp.xlsx` — оригинальная учебная работа владельца: чек-лист и три тест-кейса по предоставленному флоу оплаты. Исходный флоу не сохранился. Файл опубликован без редактирования.
- `documents/certificate.pdf` — сертификат VK Education.
- `images/` — иллюстрации и фон. Старые архивные листы сохранены, но не используются на странице.

Дело № 42. Отдельные разделы «Архивное дело», «Досье» и Weather App убраны. Практика и сертификат объединены в «Материалы». Описание навыков сохранено.
