# Портфолио Семёна Ефанова

Статический сайт для GitHub Pages. Откройте `index.html` в браузере: установка и сборка не нужны. Все пути относительные, сайт работает и в подпапке репозитория.

## Содержание

- `index.html` — тексты и разделы.
- `style.css` — оформление и адаптация для телефона.
- `desk.css` — боковой декор стола, материалы, текстовый архив и контакты.
- `script.js` — просмотр изображений; Escape закрывает просмотр.
- `images/` — оригинальные утверждённые изображения без изменений.
- `documents/` — место для будущих PDF.
